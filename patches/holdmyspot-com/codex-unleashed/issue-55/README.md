# Consistent regression checks across build systems

## Intent

Codex Unleashed reports the same CLI identity in Cargo and Bazel builds. The
published configuration schema is available to Bazel regression tests, which
compare it exactly with the schema generated by the CLI.

Issue: https://github.com/holdmyspot-com/codex-unleashed/issues/55

## Base and dependencies

Base: `rust-v0.161.0`, commit `979011409de0a60b52f179721948e65531d26144`.

- `cli-version-identity.patch` follows
  `../branding-and-app-server-distribution/add-branding-and-build-metadata.patch`.
  It pins the existing `codex-cli` command identity explicitly and retains the
  version regression test.
- `schema-test-data.patch` applies independently to the base. It declares the
  fixture's visibility, test data, and manifest-relative location, and includes
  a fixture-access regression test. The exact-byte comparison from
  `../schema/refresh-config-schema.patch` remains unchanged and follows it in
  the complete patch queue.

The patches introduce no feature flags or configuration properties.

## Reproduction

Without the CLI repair, the Bazel version test receives `codex` where Cargo
receives `codex-cli`. Without the schema repair, the Bazel schema regression
fails with a missing published-fixture error.

## Verification

The maintained `ci` workflow runs `just fmt-check` on the prepared checkout.
The maintained `Bazel` workflow runs the complete platform matrix through
`.github/scripts/run-bazel-ci.sh`, preserving its remote-cache configuration.

Focused checks use that same wrapper with `test`,
`--test_tag_filters=-argument-comment-lint`, and these targets:

- `//codex-rs/cli:cli-build_info-test`
- `//codex-rs/config-schema:config-schema-published_schema-test`
- `//codex-rs/config-schema:config-schema-codex_unleashed-test`

Expected results: formatting passes, the CLI identity is identical in both
build systems, the fixture is accessible, and generated and published schema
bytes match exactly. Verify the emitted patches on a fresh prepared checkout.

## Upstream status

These repairs cover downstream branding and schema regression checks on the
